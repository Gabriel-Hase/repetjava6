lista java repetição - 6. Faça um programa que leia a variável N (número de horas trabalhadas de um operário).
Calcule o salário sabendo-se que ele ganha R$10,00 por hora. Quando o número de horas
execer a 50, calcule o excesso de pagamento armazenando-o na variável E, caso contrário
zerar tal variável. A hora excedente de trabalho vale R$20,00. No final do processamento
imprimir o salário total e o salário excedente. O programa só deve parar de rodar quando o
usuário responder “S” na seguinte pergunta, “Deseja encerrar o programa?”.
